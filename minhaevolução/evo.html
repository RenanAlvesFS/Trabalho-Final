Minha Evolução

Quem eu era no início do semestre

Quando entrei no curso, eu tinha pouco conhecimento em programação e muita curiosidade para aprender, me interessei pelo tema pois meu tio estuda esse assunto e sempre gostei de tecnologia.Minhas expetativas eram de aprender a criar sites, melhorar desing até o fim deste primeiro semestre.

Quem eu sou agora

Agora, após o primeiro semestre, sinto que evolui bastante, aprendi a criar sites, a usar o VS Code e a usar o GitHub. Nesses meses, já fiz varíos projetos utilizando o HTML e o CSS, Onde incluia imagens, links, textos, videos, animações utilizando apenas css, deploys no github e muito mais.

Meu próximo objetivo

Meu Próximo objetivo é aprimorar o que foi aprendido ao decorrer do semestre, aprender novas tipos de linguagens, como JavaScript para melhorar sites e me desenvolver cada vez mais como desenvolvedor. Aprender animações no JavaScript para colocar em sites deixando mais bonito visualmente e suave/interativo.
