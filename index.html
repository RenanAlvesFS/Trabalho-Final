Sobre minha evolução

EXPLORE

  • Aula 1

    Introdução ao Desenvolvimento Web:

    Aprendemos os tipos de linguagens, tipos de desenvolvedores e instalação do VS Code, extensões.

  • Aula 2

    HTML Básico:

    Tags estruturais, textos, títulos/hierarquia (h1-h6), links e imagens.

  • Aula 3

    Formulários HTML:

    Aprendemos a criar formulários com campos de texto, e-mail, senha, botões e caixas de texto.

  • Aula 4

    CSS Básico:

    Aprendemos as propriedades básicas do CSS, como cor, fonte, espaçamento, posicionamento e seletores (tag, classe, ID).

  • Aula 5

    Box Model:

    Aprendemos sobre margem, padding, borda e a propriedade box-sizing: border-box,Border-Radius.

  • Aula 6

    Flexbox:

    Aprendemos a utilizar o Flexbox para criar layouts flexíveis e responsivos.

  • Aula 7

    Grid Layout:

    Aprendemos a utilizar o Grid Layout para criar layouts manipulando imagens.

  • Aula 8

    Fonts+Variantes:

    Aprendemos a utilizar fontes personalizadas e a aplicar para criar designs mais interessantes.

  • Aula 9

    Media Queries:

    Aprendemos a utilizar media queries para criar layouts responsivos que se adaptam a diferentes tamanhos de tela.

  • Aula 10

    Animações CSS:

    Aprendemos a criar animações simples com CSS, utilizando propriedades como transition e animation.

  • Aula 11

    Keyframes:

    Aprendemos a criar animações mais complexas utilizando keyframes para definir os estados intermediários da animação.

  • Aula 12

    Projeto Integrador:

    Aplicamos todos os conhecimentos adquiridos para criar um projeto integrador, onde desenvolvemos um site completo utilizando HTML e CSS.
